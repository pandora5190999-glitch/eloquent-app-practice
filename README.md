# eloquent-app-practice

## 概要
COACHTECH 教材 Tutorial 9-4「Eloquent ORM ハンズオン演習」で作成した成果物です。


## 使用技術
- PHP 8.x
- Laravel 10.x
- Eloquent ORM
- MySQL


## 学んだこと
- POSTモデルとマイグレーションを作成する
- コントローラーを作成する
- 実装する

## 動作確認
ブラウザで確認する。Postモデルとマイグレーションを同時作成し、マイグレーションでテーブル構造を定義・実行する。コントローラーを作成し、ルートを設定して実装し、動作を確認する。
